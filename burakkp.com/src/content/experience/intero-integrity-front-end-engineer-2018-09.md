Intero is an inspection and industrial services company. The company provides a complete range of services to the oil, gas, and petrochemical industries around the world. The R&D department develops monitoring and reporting applications for internal staff and clients, which requires high-quality user-friendliness.   The software team was responsible for improving legacy applications and developing new applications with high-quality code in line with the needs. The software team mainly used the LabVIEW stack, and I used CEF (Chromium Embedded Framework) in development, Node.js, Electron.js, and React.js.  The software team where I work as a frontend developer was using waterfall methodologies. As a front-end developer, My main task was legacy application bug fixing, improving usability, and apply modern front-end technologies to applications.
